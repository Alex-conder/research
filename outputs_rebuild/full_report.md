## 2. R2：两层门设计对决（verdict = 产品定符号层）

规格：B=1000 × 11 coverage 档（1.0→0.5 步 0.05）× 12 组合；
判定 = 跨 coverage 配对差均值的 95% percentile CI 是否不含 0（同一重采样跨档配对）。
臂定义（修正案 1 A1）：
(a) 纯就地探针（5-fold OOF 概率）；(b) 纯符号层 = 兄弟数据集就地探针系数符号 ×
目标侧无监督 z-score 后点积（零训练，原始幅度排序）；(c) 两层门 = 符号层方向 ×
就地探针概率在符号组（方向组）内的 5-fold OOF isotonic 重校准（连续）。

判定链：scf-RPE1 产物缺失（N/A）；scf-K562 无同引擎兄弟产物，符号臂不可得
（仅臂 (a) 入档，预注册已留痕）→ 臂 (b)/(c) 比较实际可执行 **10 组合**
（分母口径详见偏离记录 D1）。两层臂 CI 优于符号臂（且方向为两层）的组合 = **0**；
GEARS-RPE1 上两层臂显著**差于**符号臂（见下表）→ 0 < 8 → **产品定符号层**。

| 组合 | n | 两层 − 符号（均值 [95% CI]） | 符号 − 就地（均值 [95% CI]） | 两层 vs 符号 秩相关 / 最大秩位移 |
|---|---|---|---|---|
| GEARS / K562 | 217 | −0.017 [−0.043, +0.011] | −0.016 [−0.050, +0.012] | 0.67 / 115 |
| GEARS / RPE1 | 306 | **−0.046 [−0.066, −0.027]，符号胜** | −0.055 [−0.081, −0.033]，符号胜 | 0.71 / 160 |
| scGenePT / K562 | 217 | −0.028 [−0.083, +0.020] | −0.008 [−0.044, +0.022] | 0.58 / 133 |
| scGenePT / RPE1 | 306 | +0.001 [−0.022, +0.021] | −0.001 [−0.039, +0.035] | 0.79 / 157 |
| scFoundation / K562 | 45 | 符号臂不可得（仅就地臂入档） | — | — |
| scGPT / K562 | 217 | +0.005 [−0.013, +0.020] | −0.007 [−0.055, +0.033] | 0.77 / 139 |
| scGPT / RPE1 | 306 | −0.005 [−0.026, +0.015] | −0.014 [−0.041, +0.013] | 0.76 / 160 |
| Geneformer / K562 | 217 | −0.001 [−0.020, +0.015] | −0.002 [−0.050, +0.035] | 0.81 / 133 |
| Geneformer / RPE1 | 306 | +0.008 [−0.008, +0.022] | −0.032 [−0.070, +0.001] | 0.82 / 157 |
| UCE / K562 | 217 | −0.001 [−0.020, +0.015] | −0.003 [−0.055, +0.046] | 0.79 / 141 |
| UCE / RPE1 | 306 | +0.003 [−0.016, +0.022] | −0.032 [−0.084, +0.016] | 0.85 / 158 |

读数要点：
- 就地拟合的信息未超出可携带方向：10 组合中两层 − 符号的 CI 全部含 0，
  唯一不含 0 的组合（GEARS-RPE1）方向为两层**更差**。这与深潜攻击 2
  （符号基线 0.768 覆盖探针迁移 0.758）同向互证。
- 符号层（零训练、跨数据集携带）≥ 就地探针：符号 − 就地差值在 10 组合中
  9 个为负（符号更好），GEARS-RPE1 显著、Geneformer-RPE1 贴近显著
  （CI 上界 +0.001）。探针"降为辅助"有实测支撑。
- 诊断列（非锁定）：符号分与两层分秩相关 0.58–0.85、最大秩位移 115–160，
  说明第二层确有重排，但重排不转化为带内 precision 增益——排除
  "操作化掩盖增益"的替代解释。
- scf_k562 仅就地臂：单臂无臂间比较，按预注册留痕出局（臂比较分母）。

产物：`two_layer_gate.json`、`two_layer_gate.png`。

## 3. 对论文重写的具体建议

依锁定骨架（prereg §重构后的论文骨架），按本次判定落地：

1. **Abstract**：删探针迁移 AUROC 卖点句；替换为"零训练、跨数据集可携带的符号层门 +
   实测 coverage-precision 权衡表（11 coverage 档）"。不要提两层门产品。
2. **Results 签名节（A 档：以成本叙事重建，不整删）**：
   - 主图 = 解析度-样本量曲线（signature_resolution.png）：签名从"涌现性质"改写为
     "成本可测量的工程问题"，报 4/12 组合（scf-RPE1 N/A）在全量 n 有 ≥2 稳定特征。
   - 给"解析首个稳定签名所需扰动数"的网格读数表：GEARS 两数据集 n=15 即解析出
     首个稳定特征、GEARS-RPE1 n=15 达 2 个；scGenePT-K562 需 n=120 才达 2 个——
     用作"部署前采样预算"的定量依据。
   - 如实写 embedding 类解析度弱（scgpt_k562 / uce_k562 全量 0 稳定）与
     scf_k562（n=45）小样本不可解析实例（1/9）。
3. **Results 门节（产品 = 符号层）**：
   - 交付物 = 纯符号层门（零训练：兄弟数据集就地探针系数符号，直接携带）+
     实测 coverage-precision 权衡表（two_layer_gate.png 的 symbol 臂轨迹，
     分引擎 × 数据集）。
   - 两层门作为 "explored and rejected" 设计写一段：预注册两档制 + 全量实测
     0/10 组合胜出（GEARS-RPE1 显著更差），结论是"就地拟合的信息未超出可携带
     方向"。这段与攻击 2 互证，是稀缺的诚实信号。
   - 就地探针降级为辅助/诊断工具（如部署后本地校准的候选输入），
     不再作为迁移卖点。
4. **Discussion**：新增机理解释段——为何零训练符号层不输就地探针（探针在小样本
   上拟合的是扰动特异性而非模型可靠性；方向是可携带的、幅度校准是数据集特异的）。
   引用 R1 的解析度曲线说明"就地校准本身有样本量成本"。
5. **附录**：深潜攻击 1/2/3 全档（`redteam_20261024/deep/gating_attacks.md`，
   含 RPE1 弱相关 p=3.5e-5 一并报出堵审稿人）+ 本次 R1/R2 预注册、修正案 1、
   偏离记录与本报告。

## 4. 留痕与口径声明

- 臂 (c) 操作化按修正案 1 A1：符号组 = 符号层方向组（sign(score)），组内
  5-fold OOF isotonic 重校准就地探针概率；臂 (c) 分数 = 方向 × 重校准概率（连续）。
  小组/单类组无法校准时退回原始探针概率（全量与 B=1000 次重采样均未触发该回退，
  组内最小样本足以分 5 折）。
- R1 embedding 类特征口径（风险 R-3）：pred_emb_norm / delta_emb_norm /
  log_n_cells / target_in_input_space；true_emb_norm 为真值侧量按泄漏纪律排除。
- R1/R2 读数均为网格点读数、不插值（风险 R-4）。
- R2 带内 precision 与 step6b 同口径（被标记查询中确为最差一半的占比）。
- scf-RPE1 产物缺失、scf-K562 符号臂不可得，均按预注册/修正案留痕，未静默改分母。
- smoke 数字未进入锁定判据（smoke 报告纪律）；全量判定仅依本报告第 1、2 节数字。
