# research

Reproducibility package for the manuscript

> **How Much Does a Virtual-Cell Model Know About Its Own Errors?**
> *An Internally Timestamped Audit of Cheap Reliability Gating*
>
> Teng Huang, Xu'ang Wu — Center for Brain-Inspired Computing Research, Tsinghua University.

## What this repo contains

| Path | Content |
|---|---|
| `vcgate/` | Released Python package: cheap reliability gating for single-cell perturbation-response predictions (model-side features + L2 logistic probe, pre-registered protocol) |
| `step*.py` | The analysis pipeline: GEARS training → gate probe → closed-loop routing → external validation (Norman/MCF7) → multi-dataset (Adamson/Dixit/Norman) → task-utility (G-C) → conformal abstention (G-D) |
| `preregistration.md` + `prereg_*.md` | Locked, internally-dated protocols (the paper's pre-registration record) |
| `outputs*/ , inputs_final/` | Small tabular artifacts (CSV/JSON) and markdown verdicts that back the figures and tables |

## Install (vcgate)

```bash
pip install ./vcgate            # runtime deps only
pip install ./vcgate[h5ad,dev]  # + anndata (ctrl-mean from h5ad) + pytest
```

## Library use

```python
import numpy as np
from vcgate import compute_features, oof_gate_scores, gate_auroc, median_split_labels

feat = compute_features(pred_expr, perts, pred_genes, ctrl_mean)
feat["log_n_cells"] = np.log1p(n_cells)
y = median_split_labels(1.0 - pearson_delta)   # worst-half labels
scores = oof_gate_scores(feat.values, y)        # high = likely wrong
print(gate_auroc(y, scores))
```

## Reproduce

The pipeline is a sequence of `stepNN_*.py` scripts. Entry points, in order:

1. `step1_gears_baseline.py` / `step1_run.py` — train GEARS on Replogle 2022 K562/RPE1
2. `step6_gating_probe.py` / `step6_run.py` — the 9-feature L2-logistic probe (stratified 5-fold)
3. `step7_routing.py` … `step10_two_layer_gate.py` — closed-loop routing and the sign/symbol layers
4. `step14_external_mcf7_validation.py`, `step15_norman_predict.py`, `step16_external_protocol.py` — external stress tests
5. `step17_multidataset.py` — multi-dataset expansion (G-A)
6. `step22_task_utility_gc.py` — task-level utility (G-C)
7. `step20_reliability_conformal.py` — conformal abstention arm (G-D)

Run order and locked designs are stated in `preregistration.md` and the corresponding `prereg_*.md`.

## Data availability

- **In this repo**: all small tabular source data (per-dataset gate scores, probe features, conformal decisions, multi-dataset predictions) under `outputs*/`.
- **Not in git (regenerable / large)**: GEARS model checkpoints (`.pt`), predicted-expression tensors (`.npz`), and raw Perturb-seq inputs. These are regenerated by `step1_run.py` and downstream scripts, or available from the authors on request.
